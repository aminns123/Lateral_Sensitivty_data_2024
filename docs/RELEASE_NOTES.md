# Local preparation notes — 8 September 2026

Prepared a separate lateral-sensitivity/ISF dataset containing all four thesis subjects, with Subjects 1, 2 and 4 as the primary interpretation set and Subject 3 retained as diagnostic data. Original acquisition folders and the separate CSF/PSF repository were not changed.

The package preserves raw numeric trials, all selected saved resampling inputs and fit rows, adds named-column tables, reproducible raw-profile calculations, both mode-summary variants, diagnostic fits, a data dictionary, source hashes, a complete byte manifest, and the four supplied figures. New plots and new fits are explicitly identified.

The preparation is complete as a local archive. It is not a declaration that every scientific discrepancy has been resolved. In particular, the exact historical fit writer and row-to-input linkage remain unverified; calibration/label differences are preserved; and the source plotting/fit indexing behaviors are disclosed.

Before a first public release, the owner should choose licences and confirm contributor attribution and data-sharing permissions. If historical fit provenance or intended figure conventions are later resolved, make a documented new revision while retaining the preserved sources. A future GitHub/Zenodo release should use its own metadata and DOI. No existing CSF/PSF DOI has been assigned here.
